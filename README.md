# Popkern TV — releases

Popkern TV is an IPTV player for Android TV / Google TV (and phones). The app itself contains no
channels or content; you add your own M3U or Xtream Codes sources.

## Google Play (recommended)

**[Popkern TV: IPTV Player on Google Play](https://play.google.com/store/apps/details?id=com.popkern.tv)**
— installs on TVs, Google TV, Android boxes and phones, and updates itself through Play. New
versions come out on Google Play first.

The Play version is a separate app from the APK below (different package name), so it starts
empty: add your sources again, or move them with Settings → Backup & Restore (export in one,
restore in the other) if your device has a file manager.

## Sideload APK

- Download the `.apk` from the latest [release](../../releases/latest) and sideload it on your TV.
- Once installed, the app checks this page for new versions itself
  (Settings → Updates → Check for updates) and installs them in place.

The source code lives in a separate, private repository.
